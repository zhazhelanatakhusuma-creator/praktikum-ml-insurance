# Binary, Multiclass, dan Multilabel Classification

**Nama:** Zhazhe Lhanata Khusuma

## Deskripsi
Proyek ini merupakan praktikum Machine Learning yang membahas tiga jenis klasifikasi:
- Binary Classification
- Multiclass Classification
- Multilabel Classification

## File Proyek
- `Notebook_Classification_Zhazhe_Lhanata_Khusuma.ipynb`: notebook pengerjaan klasifikasi.
- `requirements.txt`: daftar library Python yang diperlukan.
- `datasets/`: folder untuk menyimpan dataset.

## Dataset
Notebook menggunakan sembilan dataset dari Kaggle:

### Binary Classification
1. Churn Modelling
2. Hotel Booking Demand
3. Chest X-Ray Pneumonia

### Multiclass Classification
4. Flowers Recognition
5. Leaf Classification
6. Dog Breed Identification

### Multilabel Classification
7. MoA Prediction
8. Freesound Audio Tagging 2019
9. iMaterialist Fashion 2018

Dataset tidak disertakan dalam repository. Dataset perlu diunduh terlebih dahulu dari Kaggle sesuai petunjuk di dalam notebook, kemudian disimpan pada folder `datasets/`.

## Cara Menjalankan
1. Install library menggunakan `pip install -r requirements.txt`.
2. Unduh dataset dari Kaggle.
3. Simpan dan ekstrak dataset sesuai struktur folder yang diperiksa oleh notebook.
4. Buka notebook menggunakan Jupyter Notebook atau Google Colab.
5. Jalankan cell secara berurutan.
