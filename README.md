Praktikum Machine Learning

Judul

Implementasi Machine Learning untuk Prediksi Biaya Asuransi Kesehatan Menggunakan Linear Regression dan Random Forest.

Deskripsi

Proyek ini merupakan praktikum Machine Learning untuk memprediksi biaya asuransi kesehatan berdasarkan karakteristik peserta menggunakan algoritma Linear Regression dan Random Forest Regressor.

Teknologi
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

Tahapan Praktikum
1. Membaca dan memeriksa dataset.
2. Membersihkan data.
3. Melakukan Exploratory Data Analysis (EDA).
4. Melakukan preprocessing.
5. Membagi dataset menjadi data training dan testing.
6. Melatih model Linear Regression dan Random Forest.
7. Mengevaluasi hasil prediksi menggunakan MAE, MSE, RMSE, dan R².

Tujuan
Membandingkan kinerja Linear Regression dan Random Forest dalam memprediksi biaya asuransi kesehatan.
